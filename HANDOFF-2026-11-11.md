## How to work on this machine

PowerShell. If `cargo` isn't found (*"failed to run 'cargo metadata' … program not found"*), run `$env:Path += ";$env:USERPROFILE\.cargo\bin"` or open a new terminal.

```powershell
# Pull, build, install. Installs only if the build succeeded.
$env:Path += ";$env:USERPROFILE\.cargo\bin"
git pull --ff-only
npm install
npm run tauri:build
if ($LASTEXITCODE -eq 0) {
  Get-Process sf-metadata-explorer, sf_backend -ErrorAction SilentlyContinue | Stop-Process -Force
  Start-Process .\src-tauri\target\release\bundle\nsis\Vendavis_1.0.1_x64-setup.exe -ArgumentList '/S' -Wait
  Get-Item "$env:LOCALAPPDATA\Vendavis\*.exe" | Select Name, LastWriteTime
} else { Write-Host "Build failed - not installing" -ForegroundColor Red }

# Quick checks
cd frontend;  npm run build                                  # run before every push
cd backend;   .\.venv\Scripts\python.exe -c "import main"
cd src-tauri; cargo check; cargo test
```

- **`/S` is a silent install**: no UI, and it doesn't launch the app. Without `-Wait`, PowerShell returns before the install finishes.
- **The installer name follows the version.** `bundle\nsis\` now holds both `Vendavis_1.0.1_x64-setup.exe` (current) and a stale `Vendavis_2.0.0_x64-setup.exe` (2026-11-10). Don't install the 2.0.0 one.
- Toolchain: Node 24 / npm 11, Python 3.12 (use `backend\.venv`; `python` on PATH opens the Store alias), Rust stable (MSVC) + VS 2022 Build Tools, Salesforce CLI 2.157.

## Things that will bite you

- **VR Disable All / Restore change org metadata.** Everything else in the app is read-only (plus exports). `vrm`, `gbr`, `san` are the developer's real orgs: ask before using these buttons or anything else that writes.
- **Rules of hooks.** Every `useState`/`useEffect` must come before any early `return` in a component. Breaking this caused #310. Production builds show only "Minified React error #310"; to find the culprit, reproduce in a dev build or run the `react-hooks` lint.
- **Line endings.** The Windows checkout is CRLF (`core.autocrlf`). A Linux-side git sees every touched file as fully changed; use `git diff --ignore-cr-at-eol` there. When editing from Linux/PowerShell, keep the file's existing line endings and write UTF-8 without BOM.
- **`opencode.config.json` beats Settings.** Its `"model": "gpt-4o"` can override the model chosen in Settings in dev.
- **Two different "OpenCode" credentials.** The terminal OpenCode app's key isn't readable by Vendavis. `oc_sk_` gateway keys need credits and only work with workspace-enabled models.
- **Tauri needs `backend/dist/sf_backend.exe`** even for `cargo check` (`npm run build:backend`, or an empty placeholder).
- **Error text flows through Rust** (`api_get`/`api_post` → `http_error()` → `client.js`); streaming (`apiStream`) uses `fetch` directly. Backend routes wrap errors as HTTP 500; `SessionExpiredError` is recovered from `__context__` by a global handler in `main.py`.
- **Tauri v2 capabilities:** list `core:event:allow-listen` / `core:event:allow-emit` explicitly.
- **`@opencode/sdk`** is an in-process server host, not a chat client. Don't re-add it (section 4 of `HANDOFF-2026-11-09.md`).
- **Red `NativeCommandError` after `git push` in PowerShell is harmless** (progress goes to stderr).
- **`~/.vendavis_api_key` is a plain-text secret.** Never paste or log it.
